# Surya-Shakti Solar Monitor ☀️⚡

## Overview
Surya-Shakti Solar Monitor is a simple Android application developed using Kotlin and XML that helps users monitor solar energy generation and electricity consumption.

The application calculates:
- Electricity savings
- Green energy score
- Over-generation conditions

It promotes smart and efficient use of renewable energy in households.

## Working
1. User enters solar energy generation.
2. User enters electricity consumption.
3. App calculates:
   - Savings
   - Green Score
   - Energy Status
4. App displays the final energy report.

---

## Formula Used

### Savings Calculation
```text
Savings = Solar Generation × Rate Per Unit
```

### Green Score
```text
Green Score = (Generation / Consumption) × 100
```
